# Consumer Law Secrets - Shopify Customization

**Consumer Law Secrets Shopify** contains custom theme modifications, Liquid templates, and styling overrides developed specifically for the **Consumer Law Secrets** brand (associated with Daraine Delevante). This repository centralizes the front-end Shopify tweaks, custom sections, and bespoke e-commerce functionality designed to boost conversion rates and deliver a seamless, high-converting shopping experience.

---

## ✨ Key Features

* **Custom Liquid Sections:** Bespoke sections and blocks built using Shopify's Liquid templating engine to allow dynamic content management directly from the Shopify Theme Editor.
* **Conversion-Optimized UX/UI:** Tailored checkout flow enhancements, custom product page layouts, and sticky/optimized "Add to Cart" functionalities.
* **Responsive & Mobile-First:** Ensures all custom elements, typography, and grids scale perfectly across desktop, tablet, and mobile screens.
* **Performance Tuned:** Lightweight CSS and deferred JavaScript implementations designed to keep store load times fast and aligned with Core Web Vitals.

---

## 🛠️ Tech Stack

* **Platform:** Shopify OS 2.0
* **Templating:** Shopify Liquid
* **Frontend:** HTML5, CSS3 / SCSS, Vanilla JavaScript
* **Integrations:** Third-party app styling overrides and custom metadata handling

## 🚀 Installation & Deployment

To apply these customizations to your live Shopify store, you can use the Shopify CLI or manual upload:

### Method 1: Shopify CLI (Recommended)
1. Clone this repository to your local machine.
2. Authenticate your store using `shopify login --store your-store-name.myshopify.com`.
3. Run `shopify theme dev` to preview the changes in your local environment.
4. Push to the live or staging theme using `shopify theme push`.

### Method 2: Manual ZIP Upload
1. Download this repository as a `.zip` file from GitHub.
2. In your Shopify Admin Dashboard, navigate to **Online Store > Themes**.
3. In the Theme Library section, click **Add theme > Upload zip file**.
4. Select your downloaded `.zip` file.
5. Once uploaded, click **Preview** to review the changes, and click **Publish** when you are ready to go live.
